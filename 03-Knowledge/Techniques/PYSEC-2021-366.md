# PYSEC-2021-366

> **Layer:** Execution · **CWE:** CWE-841 · **Confidence:** 80%

## Attack primitive
PYSEC-2021-366 Vyper is a Pythonic Smart Contract Language for the EVM.

## Detection
Instrument external calls, state-transition ordering and balance conservation; alert on any reentrant or post-effect external interaction.

## Remediation
Never make an external call before final state mutation; validate the return value of every untrusted call.
