# PYSEC-2024-150

> **Layer:** Infrastructure · **CWE:** CWE-400 · **Confidence:** 81%

## Attack primitive
Arrays can be keyed by a signed integer, while they are defined for unsigned integers only.

## Detection
invariant in the form `assert index < x`, the developer will suppose that no elements on indexes `y | y >= x` are accessible

## Remediation
Bound every loop by an explicit cap and reject calls whose input exceeds the cap rather than iterating on it.
