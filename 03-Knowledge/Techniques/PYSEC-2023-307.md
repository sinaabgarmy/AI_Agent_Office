# PYSEC-2023-307

> **Layer:** Execution · **CWE:** CWE-682 · **Confidence:** 83%

## Attack primitive
The intermediate floating point step can produce a rounding error if there are enough bits set in the IEEE-754 mantissa.

## Detection
Instrument external calls, state-transition ordering and balance conservation; alert on any reentrant or post-effect external interaction.

## Remediation
State the invariant formally and assert it on every state transition so violations fail closed.
