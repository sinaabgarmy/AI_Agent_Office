# Announcing a Trillion Dollar Security grant for WEBCAT

> **Layer:** Execution · **CWE:** CWE-841 · **Confidence:** 60%

## Attack primitive
Announcing a Trillion Dollar Security grant for WEBCAT The Ethereum Foundation’s Trillion Dollar Security (1TS) initiative is proud to announce a grant allocation to Freedom of the Press Foundation (FPF) to support the continued development of WEBCAT.

## Detection
Instrument external calls, state-transition ordering and balance conservation; alert on any reentrant or post-effect external interaction.

## Remediation
Never make an external call before final state mutation; validate the return value of every untrusted call.
