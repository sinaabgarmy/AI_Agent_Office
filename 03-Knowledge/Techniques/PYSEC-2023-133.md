# PYSEC-2023-133

> **Layer:** Cryptography · **CWE:** CWE-345 · **Confidence:** 84%

## Attack primitive
Prior to version 0.3.10, the ecrecover precompile does not fill the output buffer if the signature does not verify.

## Detection
Fingerprint key material and signature vectors; alert on repeated nonces, reused material, or entropy-source state anomalies.

## Remediation
Verify every input against its expected form before it can influence state or value.
